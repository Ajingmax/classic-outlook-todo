# Agent Guide

This repository is designed for coding agents such as Codex, Claude, and other local automation agents.

Use `SKILL.md` as the primary operating instruction. Use `README.md` for user-facing setup and project context.

Important defaults:

- Keep scripts and config keys in English.
- Keep public documentation bilingual when practical.
- Do not require Microsoft Graph or cloud email permissions.
- Prefer Classic Outlook COM/MAPI on Windows.
- Never send, delete, move, archive, or mark email.
